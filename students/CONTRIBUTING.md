# How to Contribute

1. Fork this repository.
2. Open your fork.
3. Go to the `students` folder.
4. Create a new file using your name, for example `rahul.md`.
5. Write your idea using the template.
6. Commit your changes.
7. Click **Contribute → Open pull request**.
8. Create the Pull Request.

The repository owner will review your contribution and merge it into the main repository.
